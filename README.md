# Nabin Kumar Mahato — Personal Portfolio

A responsive, single-page academic/research portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — complete page content
- `style.css` — responsive styling and animations
- `script.js` — navigation, reveal animations and cursor glow
- `assets/profile.png` — supplied professional photograph

## Run locally
Open `index.html` in a browser.

For a local development server:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.

## Deploy on Vercel
1. Put these files in a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: Other / Static.
4. Build command: leave empty.
5. Output directory: `.`

## Notes
The page uses only the information supplied in the provided resume. Social profile links were not invented because they were not supplied.
